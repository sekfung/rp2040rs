# rp2040rs Host Tools and Remaining Peripherals Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Complete the rp2040js feature surface beyond the 322 upstream unit tests: remaining APB peripherals, full UART/PWM/GPIO/PIO integration, GDB server, Simulator, Intel HEX/UF2 loading, embedded bootrom, and a runnable CLI.

**Architecture:** Real peripheral handles replace the remaining `UnimplementedPeripheral` stubs and register at upstream bases. GDB and Simulator operate on the single-threaded `Rp2040` handle; the CLI drives the Simulator or blocking GDB server with std-only argument parsing.

**Tech Stack:** Rust 2021, standard library only, `cargo test`, `cargo clippy`, `cargo build --release`.

**Spec:** `docs/superpowers/specs/2026-11-11-rp2040rs-design.md`

## Global Constraints

- Upstream pin: `wokwi/rp2040js` v1.4.1, commit `8693315df527adce8bf2bc315aeb4a1ca61c02a3`.
- Rust 2021; `#![forbid(unsafe_code)]`; standard library only; MIT attribution.
- Vendored `vendor/rp2040js/` is read-only reference.
- `cargo test --lib` stays exactly 322; all new coverage goes in `tests/`.
- Single-threaded `Rc`/`Weak`/`RefCell`; no `Send`/`Sync` requirement.
- Preserve existing 322 tests and integration suites at every task.
