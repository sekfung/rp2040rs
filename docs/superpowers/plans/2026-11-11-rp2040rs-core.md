# rp2040rs Core and Bus Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Implement the RP2040 memory map, bus dispatch, PPB/NVIC, Cortex-M0+ core, and port the 22 `rp2040.spec.ts` plus 126 `instructions.spec.ts` cases, raising `cargo test --lib` from 91 to exactly 239 tests.

**Architecture:** A `Rp2040` facade owns a `Rc<RefCell<BoardShared>>`, memory handles, a peripheral registry, and a `Core` handle. Bus methods scope registry/memory borrows before invoking peripherals. `Core` owns register/flags/NVIC state and executes ARMv6-M Thumb instructions through the bus. PPB exposes NVIC and SysTick registers. Later plans replace the stub APB peripherals.

**Tech Stack:** Rust 2021, standard library only, `cargo test`, `cargo clippy`, `cargo build --release`.

**Spec:** `docs/superpowers/specs/2026-11-11-rp2040rs-design.md`

## Global Constraints

- Upstream pin: `wokwi/rp2040js` v1.4.1, commit `8693315df527adce8bf2bc315aeb4a1ca61c02a3`.
- Rust 2021; `#![forbid(unsafe_code)]`; standard library only; MIT attribution.
- Vendored `vendor/rp2040js/` is read-only reference; never edit it.
- `cargo test --lib` after this plan must be exactly 239 tests: 91 foundation + 22 rp2040 + 126 instructions.
- Integration tests stay in `tests/`; do not add extra lib unit tests beyond the two upstream spec files.
- Single-threaded `Rc`/`Weak`/`RefCell`; never hold a `BoardShared` borrow while calling a peripheral/callback.
- Use explicit 32-bit wrapping arithmetic and the upstream masks exactly.

## Scope

This plan implements the CPU and bus only. APB peripherals other than PPB are registered as `UnimplementedPeripheral` stubs; Plan 3 replaces them. SIO is a minimal stub until Plan 3 (SIO tests are in Plan 3).

## File Structure

```text
src/irq.rs                      IRQ constants
src/peripherals/mod.rs          peripheral re-exports
src/peripherals/peripheral.rs   Peripheral trait, BasePeripheral, atomic_update
src/peripherals/ppb.rs          NVIC and SysTick register window
src/cortex_m0_core.rs           Core state, flags, exceptions, instruction interpreter
src/rp2040.rs                   Bus, memory map, Rp2040 facade, registry
src/test_support.rs             cfg(test) TestDriver for instruction specs
src/lib.rs                      module declarations/re-exports
```

- [ ] **Step 3: Implement memory and bus exactly like upstream**

`src/rp2040.rs` must reproduce:

- bootrom 4 KiB, SRAM 264 KiB, flash 16 MiB, USB DPRAM 4 KiB;
- flash mirrors via `address & 0x00ff_ffff`;
- registry key `(address >> 14) << 2`;
- read offset `address & 0x3fff`; write offset `address & 0xfff`;
- atomic type `(address & 0x3000) >> 12`;
- 8-bit/16-bit peripheral writes replicate the value 4x/2x;
- unaligned halfword writes split across words;
- out-of-range accesses do not panic;
- `reset()` resets core/PWM, fills flash with `0xff`;
- `load_bootrom()` copies little-endian words then resets.

Use scoped `RefCell` borrows: clone the registry entry or memory handle, drop the borrow, then call it.

- [ ] **Step 4: Implement PPB/NVIC and exception entry/return**

Port `vendor/rp2040js/src/peripherals/ppb.ts` and the exception-related parts of `cortex-m0-core.ts` needed by the 22 tests:

- NVIC ISER/ICER/ISPR/ICPR read/write, including the upstream `0xe000e` window;
- IPR3/IPR5 priority packing and `interruptPriorities` bit layout;
- VTOR lookup for exception vector;
- exception entry stacking (r0-r3, r12, lr, pc, xPSR), IPSR set to 16+IRQ;
- exception return via `BX LR` and `POP {..., PC}`;
- clearing pending user IRQ > 25 during exception entry.

The core subset must expose `sp()/set_sp`, `pc()/set_pc`, `reg(index)/set_reg`, `ipsr()/set_ipsr`, `pending_interrupts`/`enabled_interrupts` accessors, `interrupt_priorities()`, `step()`.
